# Disclaimer

This repository is a computational research manuscript by Kelechi Emeka Ogbonna (kelechiogbonna300@gmail.com).

The composition files, the evidence schedules, the host windows, the structure ranks, and the kinetic digest are in-silico objects. Nothing here is a medical device, a clinical decision-support system, a diagnostic, a dose, a protocol, or a claim of cure. No regulator has reviewed this deposit. A legal Disease Profile in this catalogue is a file that passed a rule list. It is not a patient and not a diagnosis. An infection window is a declared interval on a toy clock. It is not a cohort and not an antimicrobial schedule.

Channel names such as "amylase-shaped map" label rows of a composition file. They are not assays. The 2022 papaya table is not stored here.

The structural rule list is the one stated in Thesis #22, restated so this script can apply it. The windows and the rank key are the ones stated in Thesis #23, restated so this script can recompute them. The accept and refuse sets in this deposit were computed on the catalogue below. They are not a paste of either deposit's results file.
